An offline trophy guide and tracker for Grand Theft Auto VI on PlayStation 5: all 55 official trophies with their names, descriptions and grades, a cited guide in its own words for each one, a platinum roadmap built from the official descriptions with the one possibly missable trophy flagged, and a checklist that saves in the browser with filters by kind, a spoiler setting that hides story trophies until earned, and progress export and import. It runs entirely from its own files with no network.
## Run it
```sh
node serve.ts
```
Then open http://localhost:8080.
